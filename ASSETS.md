# Assets and sound references

The six masks in `src/main/resources/assets/nexvisuals/textures/particle/` are original procedural textures generated by `tools/generate_effect_textures.py` for NexVisuals, including the new footprint. They and that generator are dedicated to the public domain under **CC0-1.0**: https://creativecommons.org/publicdomain/zero/1.0/ . No textures were extracted from another client or mod. `--shapes footprint` generates only that mask and leaves existing textures untouched.

Hit Sounds references six sound events provided by the user's installed Minecraft resources:

| Preset | Minecraft sound event |
| --- | --- |
| Soft | `minecraft:block.note_block.harp` |
| Click | `minecraft:ui.button.click` |
| Pop | `minecraft:entity.chicken.egg` |
| Bell | `minecraft:block.note_block.bell` |
| Metallic | `minecraft:block.chain.hit` |
| Arcade | `minecraft:block.note_block.bit` |

**No Mojang audio, third-party audio, shader packs or reference-image artwork is distributed inside NexVisuals.** These are event references, not a claim of ownership or a license to redistribute Minecraft's assets. Resource packs may change the sounds heard by the user. Minecraft remains separately required.

This asset notice does not assign a license to the rest of the repository; the project owner decides its code license before publication.

Console Menu reuses the installed Minecraft panorama, logo, font and language resources through Minecraft renderers. Its bevels, panels and drifting pixels are drawn with GUI primitives. No Xbox/Legacy Console textures, audio, logo artwork or reference screenshots are bundled.

The `sky_dome`, `custom_stars`, `visual_grade`, `glow_extract` and `live_background` GLSL programs are source written for NexVisuals. Nebula, aurora, meteors, star shapes and menu wallpapers are procedural; no external sky cubemaps, videos, GIFs, shader packs or Xbox artwork are bundled. The wallpaper reference informed the calm curved-band direction of Waves, not copied pixels or UI assets. Minecraft shader includes and celestial textures are referenced from the user's installed resources, not redistributed here. The source verification tool (`tools/validate_shaders.ps1`) uses an optional local Khronos glslang executable; the validator binary is not part of the mod or repository.
